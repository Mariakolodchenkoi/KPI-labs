# Domen desc.
Система призначена для перегляду каталогу одягу, вибору розмірів та кольорів, формування замовлень покупцями та фіксування деталей покупки.

# Структура

* `spec.md` - типи звязків, сутності, атрибути, критерії прийняття
* `model.md` - ER-модель
* `DEFENSE.md` - протокол самоперевірки
