## 1. Scope

Система призначена для забезпечення роботи онлайн-магазину одягу. Вона дозволяє користувачам знаходити потрібні речі в каталозі, керувати кошиком, оформлювати замовлення та здійснювати оплату через зовнішній платіжний сервіс зі збереженням ціни одягу на момент покупки.

## 2. Actors

### People
1. Guest - відвідувач сайту
Переглядати каталог товарів, категорій та картки окремих речей

Використовувати фільтрацію та сортування товарів за ціною, розміром і кольором

Реєстрація та вхід в акаунт

2. Authenticated user - зареєстрований користувач
Додавати товари до кошика та змінювати їх

Оформлювати замовлення

Переглядати історію своїх замовлень та їх поточні статуси


3. Admin - адміністратор магазину
Входити в акаунт

Додавати нові товари, редагувати ціни, розміри та фотографії в каталозі

Змінювати статуси замовлень 

Переглядати кількість позицій на складі

### External system
1. Payment service - платіжний сервіс
Здійснювати або відхиляти оплату

## Use Cases

| ID | Use Case | Actor |
| --- | --- | --- |
| UC1 | Реєструватися| Guest | 
| UC2 | Входити в акаунт | Guest, Admin |
| UC3 | Переглядати та фільтрувати каталог товарів | Guest, Authenticated customer, Admin |
| UC4 | Керувати вмістом кошика | Guest, Authenticated user |
| UC5 | Оформлювати та оплачувати замовлення |Authenticated User |
| UC6 | Керувати каталогом та складом | Admin |
| UC7 | Підтверджувати або відхиляти оплату | Payment service |

---

### Relationships

* **include:** UC5 -> UC7 (Оформлювати та оплачувати замовлення обов'язково включає підтвердження або відхилення оплати)
* **extend:** UC4 -> UC5 (Керування вмістом кошика розширює процес оформлення замовлення)
* **generalization:** Authenticated user -> Guest (Авторизований користувач успадковує базові можливості гостя)
